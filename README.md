# AirBorder — Java task-manager coursework

An earlier Java command-line task manager, developed from the course's individual-project template. This is a separate project from the [Swift/iOS AirBorder prototype](https://github.com/MayFairMI6/AirBorder).

The source implements todo, deadline, and event commands, task listing/search, completion marking, and deletion. `AirBorder.java` dispatches commands, `Ui.java` handles console interaction, `Task.java` defines task types, and `Storage.java` contains file-storage support.

My work is recorded in the fork's commit history. The inherited course template remains part of its provenance. This is coursework demonstrating Java command handling and object-oriented organization, not a conversational AI system or travel-advice service.

## Status

The repository retains historical source, compiled artifacts, and text-test assets. The current source snapshot needs a clean-build and persistence review before it should be presented as a reproducible release. Prefer the newer iOS project for the current portfolio.

The [command guide](docs/README.md) describes the intended interaction. There are no benchmark or research results associated with this repository.
